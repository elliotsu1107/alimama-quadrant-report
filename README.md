# alimama-quadrant-report

> 万相台无界 · 四象限推广周报 / 日报生成器　**v0.1.0**

把万相台无界（阿里妈妈）后台导出的「计划报表 + 商品报表」拖进来，自动生成每个店铺一份的 HTML 报告：
用 **ROI × 潜客占比** 双轴给每个计划做四象限判定，并直接给出处置建议（加大投放 / 控比收割 / 修定向 / 关停）。

- **全本机运行**：不联网、不调用任何 API、不需要 AppKey，数据不出本机
- **单文件 HTML**（约 200KB）：零外部依赖，离线可开，可直接发给同事
- **中文交互**：双击 bat 即可，不需要敲命令
- **多店铺批量**：一个文件夹里放多个店铺的报表，一次全跑完

---

## 一、快速开始（Windows）

### 第 1 步：装环境（新电脑只需一次）

双击 `setup.bat`，它会自动创建 `.venv` 并安装 `pandas` / `openpyxl`。
（前提：电脑已装 Python 3.10 及以上。安装时会看到下载进度条，pandas 约 60MB，别关窗口。）

### 第 2 步：生成报告

**方式 A：批量（推荐，多店铺一次跑完）**

把导出的报表放进同一个文件夹，然后把**这个文件夹拖到 `batch.bat` 图标上**。

界面会依次用中文询问：

```
统计周期怎么写进报告标题？例如：2026-09-21至09-27
  周期 >
报告类型：[1] 周报  [2] 日报（直接回车按周期自动判断）
  选择 >
```

结束后询问是否打开输出目录，报告就在 `报表目录/reports/` 里：
**每个店铺一份 HTML 完整报告 + 一份 TXT 摘要**。

- 也可以一次选中**多个文件**一起拖上去（比如「计划报表 + 商品报表」两个文件）
- 也可以一次拖**多个文件夹**（一个文件夹 = 一个店铺）
- 如果直接双击 `batch.bat` 没拖东西，会提示你**一条一条输入**路径：拖第一个文件回车、再拖第二个回车、全部输完直接回车结束

**方式 B：单店铺交互**

双击 `single.bat`，按提示选文件即可。

**方式 C：命令行**

```bash
# 单个店铺
python weekly_report.py --plans 计划报表.csv --items 商品报表.csv --period "2026-09-21至09-27"

# 多个店铺一次跑完
python batch_report.py --paths ./九阳旗舰店 ./苏泊尔旗舰店 --period "2026-09-21至09-27"

# 只输出约 30 行的文本摘要（想让 AI 帮忙解读时贴这个就够了，不用发原始表格）
python weekly_report.py --plans 计划报表.csv --items 商品报表.csv --summary-file 摘要.txt
```

## 二、四象限方法论

**两个分界线都取本店大盘值**，不是拍脑袋的固定数字：

- 横轴：计划 ROI vs **大盘 ROI**
- 纵轴：计划潜客占比 vs **大盘潜客占比**

|  | 潜客占比 ≥ 大盘 | 潜客占比 < 大盘 |
|---|---|---|
| **ROI ≥ 大盘** | ① **优质拉新** — 加大投放 | ② **防守收割** — 控潜客占比 ≤ 30% |
| **ROI < 大盘** | ③ **人群矫正** — 修定向 | ④ **建议删除** — 关停 |

**样本不足**：花费 < 300 或 访问人数 < 200 的计划不做判定。
日报样本量小，会大量落入「样本不足」——所以**决策看周报，日报看趋势和异常**。

商品另按 **ROI × 花费** 分为四层：**爆款 / 潜力 / 问题 / 长尾**。
报告还会做「调整测算」：关停 ④、压降 ③ 之后大盘 ROI 会变成多少，先看清楚收益再动手。

## 三、报告里有什么

1. **核心指标卡**：花费、成交、ROI、CTR、CPC、CPM、CVR，以及**货品全站推广的花费占比与 ROI**
2. **四象限散点图**：可点击图例/散点筛选，鼠标悬停看计划全指标
3. **象限卡片**：各象限计划数、花费、占比、平均 ROI
4. **预算错配**：钱花在哪、ROI 在哪，错配了多少
5. **分场景结构**：全站推广 / 关键词推广 / 精准人群推广 / 商品运营 的堆叠对比
6. **调整测算**：基准 ROI → 关停④ → 再压降③，三种情景
7. **店铺花费 TOP10 商品**：带商品 ID、分层、花费占比、ROI、潜客占比、新客占比等
8. **计划明细 / 商品明细表**：可按名称**或 ID** 搜索、排序、分页、导出 CSV

## 四、输入文件要求

支持万相台后台导出的 `.csv` / `.xlsx` / `.xls`，**不要改动表头**（脚本靠表头识别字段）。

文件识别规则：

- 文件名含 **「计划」** → 计划级报表
- 文件名含 **「商品」** → 商品级报表
- 店铺名从文件名自动提取（去掉日期戳和关键词），例如 `九阳旗舰店_计划_20260928.csv` → 店铺名「九阳旗舰店」

导出建议：

- 时间跨度 **14~30 天**、按天粒度（周报）
- 保留「计划名字」「场景名字」「主体名称」「引导访问潜客占比」等列
- 一个店铺至少要有一份含「计划」的报表，商品报表可选（没有也能跑，只是少了商品板块）

字段识别做了容错，能处理：中英文列名混用、文件顶部有标题行 / 统计口径说明行、`¥1,234` 和 `12.5%` 这类带符号文本、比率列缺失时自动推导。

## 五、目录结构

| 文件 | 作用 |
|---|---|
| `weekly_report.py` | 主程序：四象限周报 / 日报 |
| `batch_report.py` | 批量驱动，一次跑多个店铺 |
| `batch_run.py` | `batch.bat` 的中文交互前端 |
| `analyze.py` | 通用单表分析器（`start.bat` 用的是它） |
| `run.py` | `single.bat` 的交互式入口 |
| `make_sample.py` / `selftest.py` | 生成示例数据 / 5 种格式的鲁棒性自检 |
| `sample_wanxiangtai.xlsx` | 示例数据，用来试跑 |
| `setup.bat` | 一键建环境 |
| `batch.bat` / `single.bat` / `start.bat` | 批量 / 单店 / 通用分析 三个入口 |

**常用参数**（命令行方式）：

```
--roi-thr 6.0      ROI 分界线（默认取大盘值）
--sp-thr 0.85      潜客占比分界线（默认取大盘值）
--min-cost 300     花费低于此值不判定象限
--min-uv 200       访问人数低于此值不判定象限
--top-n 15         TOP 商品榜数量
--suffix 周报      报告文件名后缀
```

## 六、注意事项

- 新目录第一次用请先跑 `setup.bat`，之后**只通过 bat 启动，不要直接双击 .py**
- 周期文案会作为文件名的一部分，输入 `2026/9/21–2026/9/27` 这类含 `/` 的写法会自动替换成 `-`（Windows 文件名不允许 `/ \ : * ? " < > |`）
- 所有 `.bat` 文件都是**纯 ASCII**：cmd 按 GBK 解析 bat，里面写 UTF-8 中文会把命令切碎报错，所以中文交互全部放在 `batch_run.py` 里
- 报告里的所有数字都来自你导出的原始报表，脚本不做任何估算或补全
